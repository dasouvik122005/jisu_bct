# BCT Project - Todo Application

This repository contains the source code for a full-stack Todo application.

## 📂 Project Structure

The project is divided into two main parts:

- **[`/todo`](./todo)**: The frontend application built with Angular 21. It provides a responsive and modern user interface for managing tasks.
- **[`/backend`](./backend)**: The backend API (work in progress) to handle data storage and business logic.

## 🚀 Getting Started

### Frontend (Angular)

To run the frontend development server:

1. Navigate to the `todo` directory:
   ```bash
   cd todo
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```

The application will be available at `http://localhost:4200/`.
