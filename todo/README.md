# Todo App Frontend

A simple, responsive Todo application frontend built with [Angular](https://angular.dev/).

## 🚀 Features

- **Task Management**: Add, edit, and delete tasks effortlessly.
- **State Management**: Keep track of completed and pending tasks.
- **Modern UI**: Clean and intuitive interface for better user experience.

## 🛠️ Tech Stack

- **Framework**: Angular 21
- **Language**: TypeScript
- **Testing**: Vitest

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [Angular CLI](https://github.com/angular/angular-cli) installed globally (`npm install -g @angular/cli`)

### Installation

1. Navigate to the frontend directory:
   ```bash
   cd todo
   ```

2. Install project dependencies:
   ```bash
   npm install
   ```

### 🏃‍♂️ Running the Application

To start the local development server, run:

```bash
ng serve
# or
npm start
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

### 🏗️ Building for Production

To build the project for production, run:

```bash
ng build
# or
npm run build
```

This will compile your project and store the build artifacts in the `dist/` directory. 

### 🧪 Testing

To execute unit tests with the Vitest test runner, use the following command:

```bash
ng test
# or
npm test
```
